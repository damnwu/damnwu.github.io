# 🚀 Портфолио damnwu с автоматической синхронизацией

Сайт полностью поддерживает **автоматическое обновление данных без необходимости менять код вручную**:

---

## ⚡ Как работает авто-обновление:

### 1. 🐙 Репозитории GitHub (Работает из коробки в реальном времени!)
* **Как это устроено:** При каждом открытии страницы JavaScript напрямую обращается к официальному открытому API GitHub (`api.github.com/users/damnwu/repos`).
* **Что происходит:** Как только ты создаешь новый репозиторий, заливаешь коммит или ставишь звезду — он **мгновенно и автоматически** появляется на твоем сайте с правильным языком, датой и ссылками!

---

### 2. 🎮 Часы в Steam (Dota 2, CS2 и др.)
Valve не разрешает браузерам делать прямые запросы к Steam API без ключа разработчика из соображений безопасности. Поэтому для Steam настроена система **GitHub Actions**:

* В репозитории уже создан готовый скрипт автоматизации: [`.github/workflows/update-steam.yml`](.github/workflows/update-steam.yml)
* Он запускается **каждые 6 часов**, запрашивает у Valve актуальное количество сыгранных часов и обновляет файл [`steam-data.json`](steam-data.json).
* **Как активировать:**
  1. Получи бесплатный ключ Steam Web API на странице: [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey) (в поле домена укажи `damnwu.github.io`).
  2. В твоем репозитории на GitHub перейди в: **Settings** -> **Secrets and variables** -> **Actions** -> **New repository secret**.
  3. Имя секрета: `STEAM_API_KEY`, значение: твой полученный ключ.
  4. Всё! Теперь каждые 6 часов часы в Dota 2 и CS2 на сайте будут обновляться сами.

---

### 3. 💬 Discord Статус в реальном времени (Lanyard)
Чтобы на сайте отображался твой реальный статус в Discord (в сети / отошел / играет в Dota 2):
* Зайди на сервер [discord.gg/lanyard](https://discord.gg/lanyard) (это бесплатный сервис присутствия для портфолио).
* Скопируй свой Discord ID (в Discord: Настройки -> Расширенные -> Режим разработчика -> правой кнопкой на свой профиль -> Скопировать ID).

## 🚀 Запуск на GitHub Pages

1. Создай репозиторий `damnwu.github.io` на GitHub.
2. Загрузи все файлы из этой папки:
   * `index.html`
   * `steam-data.json`
   * папку `.github`
3. Сайт откроется по ссылке: **`https://damnwu.github.io/`**
